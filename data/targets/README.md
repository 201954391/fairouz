# Viral protein targets

This folder will contain prepared viral protein target structures used for
molecular docking (for example PDB/PDBQT files and binding-site definitions).

No target structures are included yet. "Demo Viral Protein" in the app is a
placeholder name only.

## Rules for adding a target

- Use publicly available structures (e.g. from the Protein Data Bank) and
  record the entry ID, resolution and licence/terms of use.
- Document every preparation step (removed waters/ligands, added hydrogens,
  binding-site box) so docking runs are reproducible.
