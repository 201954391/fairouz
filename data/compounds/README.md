# Compound datasets

This folder will contain the compound libraries screened by Fairouz (for
example SMILES files with compound identifiers).

No datasets are included yet.

## Rules for adding a dataset

Every dataset added here must have an entry in the provenance table below
**before** it is used:

- Only use publicly available data whose licence allows this use.
- Record where it came from, which version, and when it was downloaded.
- Note known gaps, biases or quality issues.
- Never add patient or personal data.
